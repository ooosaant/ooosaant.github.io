# Portfolio profesional

Esta carpeta contiene una web estatica de portfolio profesional creada con HTML, CSS y JavaScript. No necesita instalar dependencias ni usar un servidor especial.

## Cómo verla en tu ordenador

Abre el archivo `index.html` con tu navegador.

## Qué editar primero

1. Cambia `Tu Nombre` por tu nombre real en `index.html`.
2. Cambia `tu.email@example.com` por tu correo en `index.html` y `script.js`.
3. Sustituye los textos de las secciones `Quien soy`, `Cualidades`, `Tecnologias` y `Proyectos destacados`.
4. Cambia los enlaces de LinkedIn y GitHub por tus perfiles reales.
5. Guarda tu foto dentro de `assets/` con el nombre `mi-foto.jpg`. La web la mostrara automaticamente.
6. Cuando termines tus proyectos en desarrollo, edita las tarjetas de `Proyectos en desarrollo` en `index.html`.

## Dónde publicarla gratis

Recomendación sencilla: GitHub Pages.

1. Crea una cuenta en GitHub si no tienes una.
2. Crea un repositorio nuevo, por ejemplo `portfolio`.
3. Sube estos archivos al repositorio.
4. En GitHub, entra en `Settings` > `Pages`.
5. En `Build and deployment`, elige publicar desde la rama principal y la carpeta raiz.
6. Guarda los cambios. GitHub te dará una URL pública.

Documentación oficial: https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages

Alternativa muy fácil: Netlify.

1. Entra en Netlify Drop.
2. Arrastra esta carpeta o un archivo `.zip` con el proyecto.
3. Netlify publicará una URL temporal o permanente si creas una cuenta.
4. Para cambios futuros, puedes volver a subir la carpeta o conectar el repositorio de GitHub.

Documentación oficial: https://docs.netlify.com/deploy/create-deploys/

## Cómo actualizar la web después

Edita los archivos en esta carpeta y vuelve a subir los cambios. Si usas GitHub Pages o Netlify conectado con GitHub, cada cambio que guardes en el repositorio puede actualizar la web publicada.
